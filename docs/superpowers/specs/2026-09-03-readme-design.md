# README Design

## Ziel

Das Repository bekommt einen kurzen, deutschsprachigen Einstieg für Anwender von KI-Agenten. Das README erklärt Zweck, Nutzung und vollständiges Skill-Angebot, ohne Inhalte der einzelnen `SKILL.md`-Dateien zu duplizieren.

## Aufbau

1. Titel und Einordnung: DACH-adaptierte Consulting-Skills für KI-Agenten.
2. Einsatz: Skills bei Strategie-, Analyse- und Entscheidungsarbeit einsetzen.
3. Katalog: Tabelle mit Skill, Zweck und Link zu jeweiliger `SKILL.md`.
4. Nutzung: Repository klonen oder gewünschte Skill-Datei in unterstützte Agent-Umgebung übernehmen; konkrete Konfiguration bleibt agentenspezifisch.
5. Struktur: Ein Ordner je Skill, `inbound/` als englischsprachige Quellvorlagen.
6. Lizenz: Verweis auf MIT-Lizenz.

## Grenzen

- Keine Installationsschritte für einzelne Agent-Tools behaupten.
- Keine fachlichen Inhalte der Skills im README wiederholen.
- Keine Änderung an bestehenden Skills oder Quellvorlagen.

## Prüfung

- Alle vorhandenen deutschen Skill-Ordner sind im Katalog verlinkt.
- Alle Markdown-Links zeigen auf vorhandene Dateien.
- README bleibt vollständig deutschsprachig und ohne Platzhalter.
